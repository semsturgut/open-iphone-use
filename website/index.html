Start with what you own

Plug in.
Add the phone.
Then use MCP.

Install and start the CLI, connect your iPhone by cable, and add it. After that it also works over Wi-Fi.

Install

curl -fsSL https://raw.githubusercontent.com/semsturgut/open-iphone-use/main/install.sh | bash

Start

open-iphone-use serve

It starts in the background and prints a Web UI: link (http://127.0.0.1:27893). Use open-iphone-use stop to stop the server.

Add your iPhone

open-iphone-use new

Or select Add phone in the web UI, where its screen appears live.

Uninstall

curl -fsSL https://raw.githubusercontent.com/semsturgut/open-iphone-use/main/install.sh | bash -s -- --uninstall

On Xcode 26 or iOS 26, install v0.0.3.

Advanced installation ↗
01

Install Xcode 27

Open it once with the iPhone connected, so it installs its developer tools on the phone.

02

Turn on Developer Mode

On the iPhone (iOS 27 or later): Settings → Privacy & Security → Developer Mode. Trust this Mac when asked.

03

Add the phone

Run open-iphone-use new or select Add phone in the web UI. The live screen appears at once; unplug later and it keeps working over Wi-Fi on the same network.

04

Connect an MCP client

Setup registers the MCP server and skill for detected clients. Use an image-capable agent; the server does not need an AI API key.

Input

Exact taps. No calibration.

Touches go to the exact point on the screen, as from a finger, so there is no pointer to aim or calibrate. Text, key chords and the Home, Lock, volume and Siri buttons work too.

Each action returns a frame captured after the input ended, and a tap result reports the point it touched. An accepted action does not prove the UI changed: the agent checks the returned screen every time.

Built for agent tools

Different from iPhone Mirroring.

Apple's iPhone Mirroring brings an iPhone to the Mac desktop. Open iPhone Use makes the screen and input available to MCP agents: a live stream from the phone, exact touches and keys, and standard tools your agent can call. The phone stays usable in your hand; iPhone Mirroring needs it locked.
