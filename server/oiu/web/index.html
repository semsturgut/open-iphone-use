Connecting

Bluetooth-connected phones

Bluetooth HID is required. Pair each iPhone in AssistiveTouch → Devices → Bluetooth Devices → Open iPhone Use, then add that phone below.

Scan each phone’s own QR code on that iPhone and approve Safari screen sharing. The first tap on its live tile prepares control. Both Bluetooth and screen sharing must stay connected.

Pair over Bluetooth, then select each phone above. Each phone appears here immediately; its live screen appears when sharing starts.
